# Group Collaboration System

## Goal
Build a system that allows students and their AI coding agents to collaborate through GitHub.

## Required Commands
- SYNC: Discover group updates and synchronize safely.
- PUB: Publish a code change and its event record.
- INT: Integrate a published change and verify it.
- REV: Review another member's code change.
- TEST: Run relevant tests and report evidence.
- STATUS: Explain the current project and group state.
- FINAL: Prepare and verify one authoritative group result.

## Collaboration Requirements
- Use GitHub to share code and structured events.
- Protect unfinished local work.
- Review actual code changes, not only commit messages.
- Detect both Git merge conflicts and semantic problems.
- Record testing results and unresolved issues.
- Allow a new AI session to reconstruct group state.
- Support human guidance and different AI coding agents.

## Expected Result
A working collaboration tool, documented commands,
and a demonstration involving multiple independent
participants.
